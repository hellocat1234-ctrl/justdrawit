ใส่ไฟล์เพลงที่นี่ (.mp3 .ogg .wav .m4a) แล้วรีสตาร์ท `npm run dev` — เกมจะเล่นต่อกันทีละเพลงแบบวนซ้ำ
ถ้าโฟลเดอร์นี้ไม่มีไฟล์เพลง ปุ่มเพลงจะถูกซ่อนไว้เอง (เสียงเอฟเฟกต์ยังใช้ได้ตามปกติ)

อย่าลืม: เลือกเพลงที่ใช้ได้ฟรีตามสัญญาอนุญาต (เช่น CC0 หรือ CC BY) และถ้าสัญญาต้องให้เครดิต
ให้เขียนเครดิตไว้ใน README.md ของโปรเจกต์ด้วย
